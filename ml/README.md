# Machine Learning Pipeline - Insurance Fraud Detection

This directory contains the data science and machine learning workflows for the system. It handles synthetic data generation, model training, evaluation, and the export of serialized artifacts (.joblib) for integration into the FastAPI backend.

## Tech Stack

- **Language**: Python 3.13
- **Package Manager**: [uv](https://github.com/astral-sh/uv)
- **Core ML**: [scikit-learn](https://scikit-learn.org/), [XGBoost](https://xgboost.readthedocs.io/), [imbalanced-learn](https://imbalanced-learn.org/)
- **Data Manipulation**: [pandas](https://pandas.pydata.org/), [NumPy](https://numpy.org/)
- **Interpretability**: [SHAP](https://shap.readthedocs.io/)
- **Visualization**: matplotlib, seaborn, plotly
- **Data Generation**: Faker

## Directory Structure

- `scripts/`: Python scripts for data generation and model training pipelines.
  - `models/`: Contains specific training scripts (`train_fraud_model.py`, `train_risk_model.py`, `train_shap_explainer.py`).
- `data/`: Destination for generated synthetic CSV datasets.
- `notebooks/`: Jupyter notebooks for exploratory data analysis (EDA) and experimental modeling.
- `artifacts/`: Serialized model files (`.joblib`) generated by the training scripts.
- `plots/`: Output directory for visualization images.

## Setup Instructions

1. **Install Dependencies**
   Use `uv` for isolated and reproducible environments.
   ```bash
   cd ml
   uv venv
   uv sync
   source .venv/bin/activate
   ```

## Model Training Workflow

The pipeline is split into logical steps to ensure reproducibility.

1. **Generate Synthetic Data**
   Since real insurance fraud data is highly sensitive, we generate synthetic data using `faker` and custom logic to simulate normal and fraudulent behaviors.

   ```bash
   python scripts/generate_synthetic_data.py
   ```

   This will output a dataset into the `data/` directory.

2. **Train Models**
   Run the specific scripts inside `scripts/models/` to train the classifiers. The models handle data loading, preprocessing, handling class imbalances (via SMOTE), and cross-validation.

   ```bash
   python scripts/models/train_risk_model.py
   python scripts/models/train_fraud_model.py
   ```

3. **Generate Explainers**
   To provide transparency in our predictions (vital for RBA and regulatory compliance), we train SHAP explainers based on the generated models.
   ```bash
   python scripts/models/train_shap_explainer.py
   ```

## Integration with Backend

Once the scripts complete successfully, the `.joblib` files are saved in the `artifacts/` folder.
For the backend to utilize these models, copy the relevant `.joblib` files from `ml/artifacts/` into the `backend/models/` directory. The FastAPI server will load them into memory upon startup via the `model_loader`.
